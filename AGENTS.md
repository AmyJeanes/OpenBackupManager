# Agent Guidance

Read [CONTRIBUTING.md](CONTRIBUTING.md) before starting. It holds the working rules, the build and test commands, and the AI policy you work under.

- The person you work for is the author and is responsible for every line.
- End commits with `Assisted-by: <agent> (<model>)`, such as `Assisted-by: Claude Code (Claude Opus 5.5)`. Never add `Co-Authored-By` for an agent, a session-link trailer or `Signed-off-by`.
- Never push, tag or release without explicit approval.
- Never open pull requests or issues, post comments or reply to reviewers unless a person has approved the exact text.
- Never weaken, skip or delete tests to make them pass.
- If a request conflicts with the policy, stop and say so.
