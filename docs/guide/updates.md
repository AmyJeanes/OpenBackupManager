# Updates

The Windows app keeps itself up to date from the project's [releases on GitHub](https://github.com/AmyJeanes/OpenBackupManager/releases). It checks when it starts and every 6 hours, and downloads any update in the background.

When an update's ready, **Restart now** installs it straight away. Otherwise it installs the next time you quit the app, or when it next starts. To check straight away, use **Check for updates** in About.

## Test versions

Test versions, also called prereleases, come out before each release so new things can be tried early. If you have a test version installed, you get test versions, and if you have a release, you only get releases. To choose for yourself, set `prereleases` in the [settings file](config.md#updates).
