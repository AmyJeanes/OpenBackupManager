# OpenBackupManager

Open-source, cross-platform backup and two-way sync for your folders, built on [rclone](https://rclone.org). OneDrive comes first, with any rclone backend to follow. Windows gets a native tray app, and every OS gets the `obm` command line and background service.

> **Status:** early development. Nothing here is usable yet.

## AI disclosure

OpenBackupManager is built with a lot of help from AI coding agents, but every change is reviewed by the maintainer before it's committed, and the overall design and structure are decided by the maintainer, not the AI. Every change also has to pass the automated tests, which run on Windows, Linux and macOS. The design is documented in [`docs/design/`](docs/design/) as each part is built.

For the detail, and the rules for AI-assisted contributions, see [CONTRIBUTING.md](CONTRIBUTING.md#how-this-project-uses-ai).
